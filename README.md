# Task Manager API

A secure backend API built with FastAPI and SQLite for user authentication and task management.

## Features
- User registration
- User login
- Token-based authentication
- Create, update, delete tasks
- User-specific task access
- Password hashing with bcrypt

## Tech Stack
- Python
- FastAPI
- SQLAlchemy
- SQLite
- Passlib/Bcrypt

## Run Locally

```bash
uvicorn app.main:app --reload
